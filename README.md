# NeteaseCloudMusicGtk4 Mugee版
> netease-cloud-music-gtk4 是基于 GTK4 + Libadwaita 构造的网易云音乐播放器，专为 Linux 系统打造，已在 openSUSE Tumbleweed + GNOME 环境下测试。在原作者的gtk4包的基础上，对前端ui做了些优化，使用更现代的页面布局以及个性化的背景图片。
> 项目初衷是网易云没有官方的软件，作为一个重度耳机依赖开发者，我实在无法忍受 wine 版本的不稳定和 gtk 版本极简页面的“极简”，所以干脆重新优化一下界面。
